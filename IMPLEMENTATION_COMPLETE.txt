╚════════════════════════════════════════════════════════════════════════════════╝

  ✓ branchId (required)         Branch ID
  ✓ search (optional)           Name or phone (case-insensitive)
  ✓ classId (optional)          Filter by class
  ✓ status (optional)           active | left | suspended
  ✓ paymentStatus (optional)    paid | partial | not_paid
  ✓ limit (optional)            1-500, default 50
  ✓ offset (optional)           Pagination offset
