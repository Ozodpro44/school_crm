USAGE EXAMPLES
================================================================================

USE HOOKS IN COMPONENTS
───────────────────────
import { useStudents } from '@/hooks/useServerData'

function StudentsList() {
  const { data: students, loading } = useStudents(branchId)
  if (loading) return <div>Loading...</div>
  return <ul>{students?.map(s => <li>{s.fullName}</li>)}</ul>
}

DIRECT API CALLS
────────────────
import { apiClient } from '@/lib/api-client'

const students = await apiClient.getStudents(branchId)
const student = await apiClient.createStudent({...})

MUTATIONS
─────────
const { mutate, loading } = useCreateStudent({
  onSuccess: (student) => console.log('Created!', student)
})
await mutate({ fullName, classId, ... })

================================================================================
TROUBLESHOOTING
================================================================================

BACKEND NOT RESPONDING
  curl http://localhost:8080/api/health
  If fails: Check backend is running (go run main.go)

CORS ERRORS
  Check backend CORS_ORIGINS includes frontend URL
  Update backend .env: CORS_ORIGINS=http://localhost:5173

API NOT FOUND (404)
  Verify VITE_API_BASE_URL is correct
  Check endpoint exists in backend API_ENDPOINTS.txt

AUTHENTICATION FAILED (401)
  Clear localStorage token
  Login again with valid credentials

RAILWAY LOGS NOT SHOWING
  Verify API key and Project ID
  Check Railway credentials in .env.local
  Test connection: railwayLogsService.testConnection()
