                            SETUP IN 3 STEPS
================================================================================

1. SET TOKEN
   echo "LOGS_TOKEN=your-token" >> backend_school_crm/.env

2. CONFIGURE FRONTEND
   echo "VITE_LOGS_TOKEN=your-token" >> frontend_for_dev/.env.local

3. TEST
   curl -X POST http://localhost:8080/api/logs/ingest \
     -H "Authorization: Bearer your-token" \
     -d '{"service":"api","level":"info","message":"test"}'
