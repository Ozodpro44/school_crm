KEY IMPLEMENTATION DETAILS
================================================================================

Response Fields (5 total):
  1. name (string) - Branch name
  2. monthlyPayment (float64) - Payment amount
  3. currency (string) - Currency code
  4. updatedDate (string) - ISO 8601 timestamp
  5. createdDate (string) - ISO 8601 timestamp

Data Source:
  - Single branches table
  - No joins needed
  - Direct column mapping

Authentication:
  - JWT token required
  - User's branch_id extracted from token
  - Returns branch-specific settings

Error Handling:
  - 400 - No branch assigned
  - 404 - Branch not found
  - 500 - Database error

Performance:
  - GET: 1 SELECT query
  - PUT: 1 UPDATE + 1 SELECT query
  - Indexed column access (id is primary key)
