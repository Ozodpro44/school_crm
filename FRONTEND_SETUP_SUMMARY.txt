================================================================================
  HOW IT WORKS
================================================================================

User Flow:
  1. Click "Forgot Password?" link on login page
  2. Modal opens - Enter email
  3. Click "Send OTP" button
  4. OTP sent to email (10 minute validity)
  5. Enter 6-digit OTP from email
  6. Click "Verify OTP" button
  7. Reset token returned
  8. Enter new password (min 6 characters)
  9. Confirm password must match
  10. Click "Reset Password" button
  11. Success! Modal closes
  12. Login with new password

Features:
  ✓ 3-step password reset flow
  ✓ Email validation
  ✓ OTP input (6 digits only)
  ✓ Resend OTP with countdown timer
  ✓ Password confirmation validation
  ✓ Error messages for all failures
  ✓ Back button to navigate between steps
  ✓ Loading spinners during API calls
  ✓ Success messages
  ✓ Mobile responsive
  ✓ Dark mode support
  ✓ Full translation support

================================================================================
  API ENDPOINTS USED
================================================================================

The component calls these 4 endpoints on the backend:

1. POST /api/auth/forgot-password
   Input: { "email": "user@example.com" }
   Output: { "message": "...", "email": "..." }

2. POST /api/auth/verify-otp
   Input: { "email": "user@example.com", "otp": "123456" }
   Output: { "message": "...", "resetToken": "uuid", "email": "..." }

3. POST /api/auth/resend-otp
   Input: { "email": "user@example.com" }
   Output: { "message": "..." }

4. POST /api/auth/reset-password
   Input: { "email": "user@example.com", "resetToken": "uuid", "newPassword": "..." }
   Output: { "message": "..." }

All endpoints are public (no JWT required)

================================================================================
  ERROR HANDLING
================================================================================

User-Friendly Errors:

Email Step:
  - Invalid email format → "Email is required"
  - Email not found → "User not found"
  - API error → Display error message

OTP Step:
  - OTP not 6 digits → Verify button disabled
  - Wrong OTP → "invalid OTP"
  - OTP expired → "OTP expired or invalid"
  - API error → Display error message

Password Step:
  - Password < 6 chars → Cannot submit
  - Passwords don't match → "Passwords do not match"
  - Password reset fails → Display error message

Network Errors:
  - All errors caught and displayed
  - User can retry
  - Clear error messages

Recovery Options:
  - Resend OTP button with countdown
  - Back button to go to previous step
  - Close modal to start over
