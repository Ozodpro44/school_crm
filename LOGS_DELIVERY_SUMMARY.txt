⚡ QUICK START (5 MINUTES)

1. Generate token:
   openssl rand -base64 32

2. Add to Railway Variables:
   LOGS_TOKEN=<your-generated-token>

3. Restart backend:
   cd backend_school_crm && go run cmd/main.go

4. Test with curl:
   curl -X POST http://localhost:8080/api/logs/ingest \
     -H "Authorization: Bearer <TOKEN>" \
     -H "Content-Type: application/json" \
     -d '{"service":"test","level":"info","message":"Test"}'

Expected response: {"status":"logged"}

❓ FREQUENTLY ASKED QUESTIONS

Q: Is the dashboard real-time?
A: Yes, it auto-refreshes every 5 seconds.

Q: What if logs aren't appearing?
A: See LOGS_QUICK_REFERENCE.md → Troubleshooting section.

Q: Can I use the same token for all services?
A: Yes, all services can share one token (different per environment).

Q: What happens if the backend restarts?
A: In-memory logs are lost. For persistence, upgrade to Phase 2.

Q: How do I rotate the token?
A: See LOGS_QUICK_REFERENCE.md → Token Rotation.

Q: Is this ready for production?
A: Yes, it's production-ready for 1-10 services. Phase 2 (PostgreSQL) 
   is recommended for larger deployments.
