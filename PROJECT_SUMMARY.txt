QUICK START
================================================================================

BACKEND SETUP:

1. Navigate to backend:
   cd backend_school_crm

2. Copy environment file:
   cp .env.example .env

3. Start PostgreSQL (with Docker):
   docker-compose up -d

4. Run backend:
   go run cmd/main.go

5. Verify:
   curl http://localhost:8080/health

FRONTEND SETUP:

1. Navigate to frontend:
   cd frontend_school_crm

2. Install dependencies:
   npm install

3. Update API configuration:
   // In your API config file, set:
   const API_BASE_URL = 'http://localhost:8080/api';

4. Run frontend:
   npm run dev

5. Open browser:
   http://localhost:3000

TESTING
================================================================================

BACKEND ENDPOINTS:

1. Health Check:
   curl http://localhost:8080/health

2. Register User:
   curl -X POST http://localhost:8080/api/auth/register \
     -H "Content-Type: application/json" \
     -d '{"email":"test@example.com","password":"password123","fullName":"Test User","role":"admin"}'

3. Login:
   curl -X POST http://localhost:8080/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{"email":"test@example.com","password":"password123"}'

4. Create Branch:
   TOKEN="[from login]"
   curl -X POST http://localhost:8080/api/branches \
     -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"name":"Main Branch","address":"123 Main St","phone":"998901234567","monthlyPayment":100000}'

See backend_school_crm/EXAMPLES.sh for more examples.

================================================================================
TROUBLESHOOTING
================================================================================

BACKEND WON'T START:
- Check port 8080 is free
- Verify PostgreSQL is running
- Check DATABASE_URL in .env
- Run: docker-compose up -d

API CONNECTION ERROR:
- Verify backend is running on port 8080
- Check API_BASE_URL in frontend
- Verify network connectivity
- Check CORS configuration

DATABASE ERROR:
- Verify PostgreSQL is running
- Test connection: psql $DATABASE_URL
- Check credentials in .env
- Reset database: dropdb school_crm && createdb school_crm

For more help, see backend_school_crm/QUICK_START.md
