================================================================================
SCHOOL CRM - GOLANG BACKEND API ENDPOINTS
================================================================================

BASE URL: http://localhost:8080/api

================================================================================
AUTHENTICATION ENDPOINTS
================================================================================

POST /auth/login
  Description: User login
  Body: { email, password }
  Returns: { token, user }

POST /auth/register
  Description: Register new user
  Body: { email, password, fullName, role, branchId }
  Returns: { id, email, fullName, role, branchId }

================================================================================
STUDENT ENDPOINTS (Protected)
================================================================================

POST /students
  Description: Create new student
  Body: { fullName, classId, phone, parentPhone, monthlyPayment, status, branchId, enrollmentDate }
  Returns: Student object

GET /students
  Query: branchId (required)
  Description: List all students by branch
  Returns: Array of Student objects

GET /students/:id
  Description: Get student by ID
  Returns: Student object

PUT /students/:id
  Description: Update student
  Body: { any student fields }
  Returns: Updated student object

DELETE /students/:id
  Description: Delete student
  Returns: { message: "student deleted" }

================================================================================

================================================================================
RESPONSE CODES
================================================================================

200 OK              - Successful GET/PUT request
201 Created         - Successful POST request
204 No Content      - Successful DELETE request
400 Bad Request     - Invalid input data
401 Unauthorized    - Missing or invalid token
403 Forbidden       - Insufficient permissions
404 Not Found       - Resource not found
500 Internal Error  - Server error

================================================================================
AUTHENTICATION HEADER
================================================================================

All protected endpoints require:
Authorization: Bearer <token>

Example:
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

================================================================================
DATA TYPES
================================================================================

PaymentMethod: "cash" | "card" | "bank"
PaymentStatus: "paid" | "unpaid" | "partial"
StudentStatus: "active" | "left" | "suspended"
UserRole: "admin" | "branch_admin" | "manager" | "accountant" | "teacher" | "student" | "parent"
Month: "01" to "12"

================================================================================
EXAMPLE REQUESTS
================================================================================

1. Login
   curl -X POST http://localhost:8080/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{"email":"admin@example.com","password":"password123"}'

2. Create Student
   curl -X POST http://localhost:8080/api/students \
     -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" \
     -d '{
       "fullName":"Ahmed Ali",
       "classId":"uuid",
       "phone":"998901234567",
       "parentPhone":"998909876543",
       "monthlyPayment":100000,
       "status":"active",
       "branchId":"uuid"
     }'

3. Record Payment
   curl -X POST http://localhost:8080/api/payments \
     -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" \
     -d '{
       "studentId":"uuid",
       "amount":100000,
       "month":"01",
       "year":2024,
       "paymentMethod":"cash",
       "status":"paid",
       "invoiceNumber":"INV-12345",
       "branchId":"uuid"
     }'

4. Get Payment Summary
   curl -H "Authorization: Bearer $TOKEN" \
     http://localhost:8080/api/payments/branch/{branchId}/summary

5. List Students
   curl -H "Authorization: Bearer $TOKEN" \
     http://localhost:8080/api/students?branchId={branchId}

================================================================================
DATABASE SCHEMA
================================================================================

Tables automatically created:
- users (user accounts and roles)
- branches (school branches)
- students (enrolled students)
- classes (school classes)
- teachers (teaching staff)
- teacher_classes (teacher-to-class assignments)
- payments (student payments)
- salaries (teacher salaries)
- expenses (school expenses)
- incomes (other income sources)
- settings (system settings)
- permissions (user permissions)
- branch_managers (branch manager assignments)

================================================================================
FRONTEND INTEGRATION
================================================================================

Configure frontend API client:

const API_BASE_URL = 'http://localhost:8080/api';

// Login example
async function login(email, password) {
  const response = await fetch(`${API_BASE_URL}/auth/login`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email, password })
  });
  const data = await response.json();
  localStorage.setItem('token', data.token);
  return data;
}

// Authenticated request example
async function getStudents(branchId) {
  const token = localStorage.getItem('token');
  const response = await fetch(
    `${API_BASE_URL}/students?branchId=${branchId}`,
    {
      headers: { 'Authorization': `Bearer ${token}` }
    }
  );
  return response.json();
}
