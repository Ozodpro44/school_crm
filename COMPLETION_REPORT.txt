API SPECIFICATION
================================================================================

ENDPOINTS:
──────────

POST /api/branches/{id}/close-month
├─ Role Required: admin, branch_admin, manager
├─ Request: {} (empty body)
└─ Response: { message, newMonth, branch }

GET /api/branches/{id}/financial-months
├─ Returns: { months: FinancialMonth[] }
└─ Ordered: year DESC, month DESC

FINANCIAL TRANSACTIONS (Payments/Expenses/Salaries):
──────────────────────────────────────────────────

POST /api/payments, /api/expenses, /api/salaries
├─ New field: financialMonthId (optional, auto-assigned)
├─ Validation: Month must be OPEN
└─ Error if closed: "cannot create [type]: current financial month is closed"

PUT /api/payments/:id, /api/expenses/:id, /api/salaries/:id
├─ Validation: Record's month must be OPEN
└─ Error if closed: "cannot update [type]: financial month is closed"

DELETE /api/payments/:id, /api/expenses/:id, /api/salaries/:id
├─ Validation: Record's month must be OPEN
└─ Error if closed: "cannot delete [type]: financial month is closed"

================================================================================
DATA FLOW EXAMPLES
================================================================================

SCENARIO 1: Creating a Payment in Open Month
─────────────────────────────────────────────
User → Frontend Form Shows Current Month (Jan 2024)
    ↓
User Fills Form and Submits
    ↓
Frontend Validates: Month is OPEN? ✓
    ↓
POST /api/payments { ..., financialMonthId: null }
    ↓
Backend: GetOrCreateCurrentMonth() → fm-2024-01
    ↓
Backend: IsMonthClosed(fm-2024-01)? NO ✓
    ↓
Backend: INSERT payment WITH financial_month_id = fm-2024-01
    ↓
Success: Payment created with month link

SCENARIO 2: Attempting Edit in Closed Month
──────────────────────────────────────────────
User Sees Edit Button → DISABLED (Month is CLOSED)
    ↓
System Shows: ClosedMonthAlert
    ↓
If User Somehow Bypasses (Direct API):
    ↓
Backend: Get payment → Has financialMonthId = fm-2024-02 (CLOSED)
    ↓
Backend: IsMonthClosed(fm-2024-02)? YES
    ↓
Error: "cannot update payment: financial month is closed"
    ↓
Response: 400 Bad Request

SCENARIO 3: Month Closure
────────────────────────
Admin Clicks "Close Month" Button
    ↓
Dialog: "Are you sure? This cannot be undone."
    ↓
Admin Confirms
    ↓
POST /api/branches/branch-abc/close-month
    ↓
Backend Transaction:
    1. Get current OPEN month (Jan 2024)
    2. Mark as CLOSED with closed_at = now()
    3. Create new OPEN month (Feb 2024)
    4. Update branch.current_financial_month_id = Feb month ID
    5. COMMIT (atomic)
    ↓
Response: { newMonth: Feb, branch: updated }
    ↓
Frontend: Month Status Updates, UI Refreshes
    ↓
Next payments go to Feb 2024

================================================================================
ROLE-BASED ACCESS CONTROL
================================================================================

ADMIN / BRANCH_ADMIN:
├─ View: ALL months for ALL branches
├─ Create: Records in ANY month
├─ Edit: Records in ANY month
├─ Delete: Records from ANY month
└─ Special: Can close months, access full history

MANAGER:
├─ View: ONLY current OPEN month
├─ Create: Records ONLY in current OPEN month
├─ Edit: Records ONLY in current OPEN month
├─ Delete: Records ONLY in current OPEN month
├─ Cannot: View old months, close months
└─ Restricted: See ManagerRestrictedAccessNotice

ACCOUNTANT:
├─ Same as Manager (view/create/edit current month only)
└─ Cannot: View history, close months

IMPLEMENTATION:
├─ Database: Foreign key constraints
├─ Backend: CanAccessMonth() validation in FinancialMonthService
├─ Frontend: useMonthAccess() hook with permission checks
└─ UI: Disabled buttons, alerts, notices
