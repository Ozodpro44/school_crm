NEW API ENDPOINTS
================================================================================

1. GET /api/payments/status/:studentId?branchId={id}
   Permission: canViewPayments
   Response: {status, amount}
   Speed: ~50ms
   
2. GET /api/payments/search/students?filters...
   Permission: canViewPayments
   Response: {data[], total, limit, offset}
   Speed: ~150-250ms
   Max Results: 500 per request

================================================================================
FILTER OPTIONS
================================================================================

  branchId (required)        - Branch ID
  search (optional)          - Student name or phone (case-insensitive)
  classId (optional)         - Filter by class
  status (optional)          - active | left | suspended
  paymentStatus (optional)   - paid | partial | not_paid
  limit (optional)           - Default: 50, Max: 500
  offset (optional)          - Pagination offset
