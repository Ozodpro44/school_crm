================================================================================
  NEW API ENDPOINTS
================================================================================

1. POST /api/auth/forgot-password
   - Request OTP for password reset
   - Input: { "email": "user@example.com" }
   - Output: OTP sent to email

2. POST /api/auth/verify-otp
   - Verify OTP and get reset token
   - Input: { "email": "user@example.com", "otp": "123456" }
   - Output: Reset token (valid 1 hour)

3. POST /api/auth/resend-otp
   - Resend OTP if expired or not received
   - Input: { "email": "user@example.com" }
   - Output: New OTP sent to email

4. POST /api/auth/reset-password
   - Reset password using reset token
   - Input: { "email": "user@example.com", "resetToken": "...", "newPassword": "..." }
   - Output: Password reset success message

================================================================================
  QUICK START (3 STEPS)
================================================================================

1. INSTALL DEPENDENCIES
   cd backend_school_crm
   go mod tidy
   go mod download

2. START REDIS
   docker run -d -p 6379:6379 redis:latest

3. CONFIGURE .env
   REDIS_URL=redis://localhost:6379/0
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=587
   SMTP_USER=your-email@gmail.com
   SMTP_PASS=your-app-password
   SMTP_FROM=noreply@schoolcrm.com

4. RUN BACKEND
   go run cmd/main.go

5. TEST ENDPOINT
   curl -X POST http://localhost:8080/api/auth/forgot-password \
     -H "Content-Type: application/json" \
     -d '{"email":"admin@example.com"}'
